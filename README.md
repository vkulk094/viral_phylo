# viral_phylo
My thesis code repo

Run the scripts in numerical order. Some scripts are accompanied with SLURM submission scripts that may specify important parameters and conditions for technical reasons and/or performance enhancement. These scripts may even be necessary to run the code if features like local node storage are used.

The IMG/VR v4.1 high confidence proteins database can be downloaded directly from their website at the URL: https://genome.jgi.doe.gov/portal/IMG_VR/IMG_VR.home.html
Note: You need to register with the JGI Genome Portal to download the data files in acccordance to their usage policy. I prefer using their Globus endpoint for easy transfer to my compute cluster.
